## What's new in 2.13.0

Two settings for playing without re-presses (Activation Distance set huge, so a release lasts until the pen lifts). Both are off by
default; nothing changes unless you set them.

- **Hold Allowance** (default 1 = off): once a press has lasted Hold Time, the fast release detector tolerates this many times faster
  dips. Taps are not affected.
  - Drag ends often dip and then hold before the real lift. Without re-presses, the old release on that dip cut the drag for the
    50–250 ms until the lift.
  - On the 2026-10-19/20 gameplay logs, 4 (with Release Distance 1000) removed 69 of 72 such cut-outs. Drag ends then release
    about 20 ms later than before.
  - Leave it at 1 when re-presses are on: it would swallow re-clicks inside drags.
- **Rebound Distance** (default 0 = the re-press distance, as before): the rise that makes a landing bounce count as a bounce.
  - With a huge Activation Distance the bounce rule never triggered, so landing dips released for good.
  - 10 restores it. That removed 8 of 38 landing cut-outs, at no cost to taps.

## Settings to change (coming from 2.12.0)

None required. For the no-re-press setup:

- **Activation Distance:** 10999 (or 1000, see below).
- **Hold Allowance:** 4.
- **Release Distance:** 1000.
- **Rebound Distance:** 10.

With Activation Distance **1000** instead of 10999, a release can be undone only by a deliberate push of 1000+ raw. That brings back
drags that start light, nearly lift, then press hard; with 10999 the whole drag is lost. It costs about one extra re-press per minute
on big pushes.

Replace `RapidTrigger.dll` (Windows: `%localappdata%\OpenTabletDriver\Plugins\<folder>\`) and restart OpenTabletDriver.
