## What's new in 2.10.0 (and 2.9.0)

- **Glitch Jump** (new setting): the PTK-670 custom firmware (ring500 83a52e3c) sometimes sends one or two impossible samples
  while the pen is pressed hard, for example 8191 → 692 → 8191 or 8117 → 0 → 8113. Each one used to release and re-press
  mid-drag, and once it left a hold released. With Glitch Jump set, a single-sample jump at least that large is held back for
  up to Dropout Time and ignored if pressure comes straight back. Real pressure changes stay under ~1800 per 2 ms sample, so
  real presses and releases are not delayed. Default 0 = off: with defaults everything behaves exactly as in 2.9.0.
- **Landing bounces** (2.9.0): a release that came due inside Press Holdoff is dropped when the holdoff ends if pressure is
  already rising again, so a landing overshoot no longer double-clicks.

## Settings to change (PTK-670 at 1000 Hz motion sync ON, coming from 2.9.0)

1. Replace `RapidTrigger.dll` in your Rapid Trigger plugin folder (Windows: `%localappdata%\OpenTabletDriver\Plugins\<folder>\`)
   with the one from this release, then restart OpenTabletDriver.
2. In the **Rapid Trigger** filter, change:

| Setting | From | To |
|---|---|---|
| Glitch Jump | (new, 0) | **2500** |
| Dropout Time | 3 | **4** |
| Activation Percent | 0.75 | **0** |
| Tap Allowance | 0.1 | **0.2** |
| Release Distance | 300 | **600** |

3. Keep everything else. Full list for checking: Contact Threshold 4, Phantom Contact Pressure 8191, Phantom Confirm Time 20,
   Dropout Pressure 8190, Lift Threshold 2, Activation Distance 10, Fast Fall Speed 12, Fast Fall Percent 0.2, Fast Release
   Distance 35, Re-press Allowance 0.3, Press Holdoff 12, Release Ratio 0, Max Release Distance 1000, Drift Time Constant 10,
   Press Drift Time Constant 0, Hold Time 400, Hold Release Multiplier 1, Firmware Sample Clock on, Preserve Pressure off.
   Pen tip threshold 0% in the Bindings tab.
4. Apply / save the settings.

What it changes, measured on three Windows recordings (~11 min, including a 339 s S4 League session): re-press after a
re-click's lowest point 10.9 → 5.3 ms; re-presses inside strokes in the game session 46 → 11 (all 35 caused by glitches are
gone, the rest are re-clicks and small wobbles); all 9 labelled re-clicks still caught; no slow drag dip released; 0 light-drag
cut-outs in the synthetic tests.
