## What's new in 2.11.0

- **Minimum Click** (new setting, off by default): every click lasts at least this long; releases, lifts included, wait until
  then. Meant for games that read the mouse button once per frame, which can miss a click shorter than a frame (rapid releases
  make quick taps ~12 ms clicks). It never delays a press and never moves the release of a click that is already at least that
  long. Not needed for games that read input much faster (e.g. 3000 ticks per second).
- New recording and analysis tooling for the second S4 League session (`tools/Tune` now scores all four 2 ms recordings and
  counts clicks shorter than one 60 fps frame).

## Settings to change (coming from 2.10.0)

None. Replace `RapidTrigger.dll` (Windows: `%localappdata%\OpenTabletDriver\Plugins\<folder>\`) and restart OpenTabletDriver;
with Minimum Click at 0 it behaves exactly like 2.10.0. Optionally turn on **Enable Diagnostics** for a session (CSV files in
`~/rapid-trigger-logs`, Windows: `C:\Users\<you>\rapid-trigger-logs\`) to record exactly when the plugin pressed and released.
